# سجل الإصدارات

## 4.1.0 — 2026-11-20
- المشروع في GitHub مع فحص تلقائي لكل تعديل.
- شريط الأخبار يقرأ ملفاً جاهزاً يُحدَّث كل 15 دقيقة على GitHub (rss2json احتياطي فقط).
- قياس أسبوعي للسرعة والسيو عبر Lighthouse.
- الأرشيف الزمني: سنوات وأشهر، بحث فوري، تصفية بالتصنيف، ترتيب، إحصاءات (`?archive` و`/p/archive.html`).
- رابط «الأرشيف» يُضاف تلقائياً لروابط التذييل.
- خطوات تثبيت آيفون تُنشأ عند الطلب فلا تظهر في نص الصفحة لمحركات البحث.
- إمكانية الوصول: ترتيب عناوين التعليقات، عناوين للإطارات المضمّنة، أسماء لأزرار المقال على الجوال، تطابق أسماء أزرار الخط واللغة مع نصها.
- السرعة: صورة الخبر الرئيسي تُحمَّل فوراً بأولوية عالية (كانت كسولة وتؤخر LCP).

## 4.0.0 — 2026-11-19
- لوحة تحكم مرئية (`?panel`) بخمسة تبويبات و56 خياراً، إظهار وإخفاء فوري لكل كتلة.
- رقم الإصدار في `<meta name="tcnops-version">`.
- الشريط يتحرك مع «إزالة الحركة»، والتوقف عند المرور للحاسوب فقط.
- روابط التذييل مربعات، ثلاثة في الصف.
- إغلاق النوافذ بالنقر خارجها أو السحب للأسفل.
