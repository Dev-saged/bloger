# TCNOPS 2026 — قالب بلوجر

قالب عربي أصلي لموقع [TCNOPS](https://tcnops.blogspot.com) — تصميم وتطوير ساجد العبادلة، من غزة.

## الاستخدام
الملف الجاهز للتركيب: **`dist/TCNOPS-2026.xml`** ← بلوجر: المظهر ← تعديل HTML ← الصق ← حفظ.

## البنية
| المسار | الدور |
|---|---|
| `src/skeleton.xml` | هيكل الصفحة والأقسام والأدوات |
| `src/blog.xml` | عرض المقالات والواجهة وصفحة المقال |
| `src/comments.xml` | تعليقات بلوجر القياسية |
| `src/style.css` | كل التنسيقات |
| `src/early.js` | قراءة لوحة المزايا وإخفاء الكتل قبل الرسم |
| `src/app.js` | المزايا والشريط ولوحة التحكم المرئية |
| `src/archive.js` | الأرشيف الزمني |
| `src/i18n.js` | الوضع الإنجليزي |
| `schema.py` | تعريف كل خيار في اللوحة + رقم الإصدار |
| `build.py` | يبني `dist/TCNOPS-2026.xml` |
| `feed/` | جامع أخبار الشريط (يعمل كل 15 دقيقة على GitHub) |
| `tests/` | اختبار العرض على 5 شاشات بالعربي والإنجليزي |
| `pages/` | نصوص الصفحات الثابتة |

## الأتمتة (GitHub Actions)
- **فحص القالب**: عند كل تعديل في `tcnops/` — بناء، تطابق النسخة المنشورة، XML، السكربتات، اختبار الشاشات.
- **أخبار الشريط**: كل 15 دقيقة يجمع أخبار المصادر في `feed/sources.json` وينشرها في فرع `tcnops-feed` (`ticker.json`).
- **قياس السرعة والسيو**: أسبوعياً (أو يدوياً) Lighthouse على الموقع الحقيقي ← `audit.md` في فرع `tcnops-feed`.

## إضافة مصدر أخبار
عدّل `feed/sources.json` وأضف `{ "name": "...", "url": "رابط RSS" }`.
