# استوديو المقالات (Article Studio)

لوحة PWA بملف واحد: تضغط زراً فتولّد 5/10/20 مقالاً بصورتين لكل مقال، وتسلّمك XML جاهزاً لاستيراد بلوجر.

## التشغيل
- النشر: فرع `gh-pages` (جذر المستودع) ← Settings ← Pages ← Deploy from branch ← `gh-pages` / root. الرابط: `https://dev-saged.github.io/bloger/`
- محلياً: افتح `index.html` مباشرة (المتصفح الحديث يكفي).
- التثبيت كتطبيق: قائمة المتصفح ← إضافة إلى الشاشة الرئيسية.

## المزودون (تبديل تلقائي حسب الترتيب)
| المزود | مفتاح | ملاحظة |
|---|---|---|
| Cerebras | مجاني | سريع، حد يومي سخي |
| Mistral | مجاني | خطة التجربة |
| Cohere | Trial | حدود شهرية |
| OpenRouter | مجاني | نماذج `:free`، حد يومي صغير بدون رصيد |
| Groq | مجاني | الأسرع (gpt-oss، Llama) |
| Google Gemini | مجاني | نماذج Flash |
| Pollinations | بلا مفتاح | شبكة أمان أخيرة، أبطأ |
| OpenCode Zen | مفتاح | تجريبي، المتصفح غالباً يحجبه (CORS) |
| مخصص | حسب الخدمة | أي خدمة متوافقة مع OpenAI وتسمح بـ CORS |

عند 429 أو رد فاسد أو انتهاء مهلة ينتقل المحرك للنموذج/المزود التالي ويضع المستنفد في استراحة (1-10 دقائق).

## الثبات
- المقال على مرحلتين (هيكل ثم الأقسام) بصيغة وسوم `[[title]]` بدل JSON، فلا ينكسر بعلامات التنصيص؛ الأقسام الناقصة تُستكمل تلقائياً.
- ذاكرة صحة النماذج (localStorage): النموذج الذي يفشل 3 مرات متتالية يُتجنَّب ساعة، والناجح يُقدَّم. نماذج omni/vl/thinking مستبعدة.
- تبويب المزودون: اختبار كل مزود، وتصدير/استيراد كل المفاتيح (ملف JSON، مع GitHub Token اختيارياً).
- التصدير: «فحص التوكن» يوضح سبب 403 قبل رسم الصور.

## سير العمل
1. توليد: اختر العدد والمصدر (أخبار ESPN الحديثة / شروحات دائمة / مواضيعك) ← «ولّد».
2. المقالات: معاينة، إعادة توليد، حذف.
3. التصدير: Token لـ GitHub (Fine-grained، Contents: Read and write لمستودع واحد). تُرسم الصور وتُرفع بإيداع واحد إلى فرع `blog-images` وتُثبَّت روابطها بالـSHA عبر jsDelivr، ثم يُنزَّل XML.
4. بلوجر: الإعدادات ← إدارة المدونة ← استيراد المحتوى.

## القواعد المدمجة ضد التلفيق
- بوجود خبر ESPN: لا يُسمح للنموذج إلا بما في العنوان والوصف. بدونه: شرح عام بلا أرقام متغيرة.
- المقال يُرفض ويُعاد عبر مزود آخر إن قلّ عن 380 كلمة أو نقصت أقسامه/حقائقه/أسئلته.
- HTML النموذج يمر عبر مُنقٍّ (قائمة بيضاء) قبل الحفظ والتصدير. الأخبار مصدرها الوحيد: رابط ESPN.

## الاختبار
افتح `index.html#test`: محلل الوسوم، toHtml، تبديل المزودين بمحاكاة (429 ← رد فاسد ← نجاح)، XML، رسم الصور، ZIP.

## البناء
`index.src.html` + `data.json` ← `python3 build.py` ← `index.html`. (`data.json`: عناوين المنشور سابقاً لمنع التكرار + أشكال الأغلفة).
